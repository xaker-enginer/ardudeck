# Дополнительные лицензионные тексты

Некоторые зависимости публикуют npm-архив без файла лицензии. Здесь сохранены
оригинальные уведомления из их официальных репозиториев, чтобы включать их
в `apps/desktop/resources/THIRD-PARTY-NOTICES.txt` при сборке.

`manifest.json` фиксирует пакет, версию, исходный URL, основание включения и SHA256
исходного файла. Генератор проверяет этот SHA256; сетевые запросы при генерации
не выполняются. Тексты не переводятся и не заменяются типовым шаблоном лицензии.

Где возможно, выбран коммит, указанный в метаданных опубликованной версии npm.
В остальных случаях явно указано, что это дополнительное уведомление из более
нового состояния официального репозитория. Оно не выдаётся за файл, находившийся
в старом npm-архиве.

В частности, MIT-текст Mapbox jsonlint добавлен автором проекта 30 марта 2026 года,
после публикации используемого npm-архива 2.0.2. У `xz-decompress` сохранён исходный
заголовок с атрибуцией xzwasm, XZ Embedded и walloc; отдельный текст walloc взят
из его официального репозитория. Метаданные и уведомления не заменяют неизвестный
лицензионный документ вымышленным разрешением.

Генератор охватывает все установленные npm-пакеты как расширенный перечень,
включая инструменты сборки и тестов. Запись в перечне не означает включения
пакета в установщик. Для пакетов без отдельного текста сохраняются объявленный
идентификатор лицензии, автор из метаданных и ссылка на исходный архив; такие
случаи перечислены в JSON-отчёте генератора.

```powershell
node tools/generate-third-party-notices.mjs
```

Для нестандартного Rust-окружения используются `CARGO_HOME` или
`--cargo-home=<каталог>`, а также `--rust-sysroot=<каталог toolchain>`.
`--report=<путь.json>` сохраняет подробный отчёт. При обычной установке генератор
берёт стандартный Cargo home и результат `rustc --print sysroot`.
